MUSH PORTFOLIO - VERCEL READY

This is a standalone static website.

1. Upload index.html to the ROOT of your GitHub repository.
2. In Vercel, import that repository.
3. Framework Preset: Other.
4. Build Command: leave empty.
5. Output Directory: leave default (for Other, Vercel serves the project root when there is no public folder).
6. Root Directory: ./ (repository root).
7. Deploy.

All images and the research report are embedded in index.html, so no assets folder is required for this standalone version.
